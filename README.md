🍽️ Omnifood Project

A modern and responsive food delivery website built with HTML, CSS, and JavaScript.
This project is part of my frontend learning journey, focused on creating a clean UI, responsive layouts, and smooth user interactions.

✨ Features

✅ Responsive design (mobile, tablet, desktop)

✅ Interactive navigation and smooth scrolling

✅ Meal showcase with hover effects and descriptions

✅ Pricing section with clear plans

✅ Contact / Call-to-action section

✅ Organized structure with separate CSS, JS, and images folders
